# Lab 04 - MVP Feature List

## MVP Decision Rule

The MVP should include the smallest set of features that demonstrates the core solution by enabling students to discover campus events, register for activities, manage their participation, and allowing organizers and administrators to manage campus events through a centralized platform.

## Not Included in the MVP

The following features are intentionally excluded because they require backend services or third-party integrations beyond the scope of the current prototype:

- Push notification reminders
- Personalized recommendations
- AI-based event suggestions
- Calendar synchronization
- QR-code attendance tracking
- Email notifications
- Mobile application version

The MVP focuses on helping students easily discover campus events, register for activities, manage their participation through My Events, and enabling organizers and administrators to manage campus events using a simple frontend prototype with browser localStorage.
