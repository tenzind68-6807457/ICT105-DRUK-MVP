# Landing Page Content

## Project Title

Smart Campus Event Hub

---

## Target User

The Smart Campus Event Hub landing page is designed for:

- University students, especially first-year students who need an easier way to discover campus activities.
- International and exchange students who need centralized access to university event information.
- Student club members and organizers who create and manage campus events.
- Campus administrators who manage and promote university activities.

---

## Headline

Discover and Participate in Campus Events Through One Smart Platform.

---

## Subheadline

Smart Campus Event Hub helps students discover upcoming university events, view complete event information, register for activities, and manage their registered events through a centralized web platform.

---

## Problem Statement

Students often miss important campus events because event information is scattered across different platforms such as social media, messaging applications, emails, and printed posters.

Based on Lab 03 customer discovery findings, students experienced difficulty finding reliable information about workshops, competitions, seminars, club activities, and university events.

Lab 08 validation showed that students needed a simpler way to discover events, register for activities, track registered events, and provide feedback after attending completed events. User testing confirmed that students, organizers, and administrators could successfully complete important tasks such as browsing events, searching events, viewing details, registering, and managing event information.

---

## Solution Description

Smart Campus Event Hub provides a centralized web-based platform where students can discover campus events, search and filter activities, view complete event details, register for events, view their registered events through the My Events page, and submit reviews after attending completed events.

The platform also supports administrators by allowing them to create, edit, update, approve, cancel, and delete event records through the Admin Dashboard.

## Benefits

From the user's perspective, Smart Campus Event Hub provides:

- A centralized platform for discovering campus events.
- Faster access to workshops, competitions, seminars, and student activities.
- Easier event registration without searching multiple platforms.
- A My Events page to view registered events and participation information.
- The ability to provide feedback after attending completed events.
- Better event management for organizers and administrators.
- Improved campus engagement for first-year and international students.

## Responsible Data Message

Smart Campus Event Hub collects only necessary information required for system operation, including:

- Basic user account information.
- Event registration information.
- Event reviews and feedback.

User information is used only for:

- Managing user accounts.
- Processing event registrations.
- Showing registered events in the My Events page.
- Improving prototype usability.

The prototype uses browser localStorage as simulated data storage and avoids collecting unnecessary sensitive information.
