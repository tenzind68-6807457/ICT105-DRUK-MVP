# User Testing Results

## 1. Testing Summary

- **Date:** July 2026
- **Number of testers:** 10 testers
- **Prototype link:** https://sonamd6807456.github.io/ICT105-DRUK-MVP/prototype
- **Testing location/platform:** Rangsit University students testing the HTML/CSS/JavaScript prototype using web browsers on desktop and mobile devices.

The purpose of the testing was to evaluate whether the Smart Campus Event Hub helps students discover campus events, view event information, register for activities, manage participation, save favorite events, and provide feedback through reviews.

The testing included student users, organizers, and administrators completing tasks related to the main system requirements.

# 4. User Feedback Summary

## Positive Feedback

Users liked:

- The centralized event discovery system.
- Simple navigation between event pages.
- Clear event information including date, location, and description.
- Easy event registration process.
- My Events page for tracking registered activities.
- Favorites feature for saving interesting events.
- Admin event management functions.

## Suggested Improvements

Users suggested:

- Adding advanced search options.
- Adding event reminders and notifications.
- Improving recommendation features.
- Adding more dashboard analytics.
- Supporting more customization options for user profiles.
- Adding campus map information for event locations.

Overall, users found the Smart Campus Event Hub useful and easy to understand. The prototype successfully solved the main problem of scattered campus event information.

---

# 5. Evidence-Based Decision

## Decision:

**Needs minor revision**

## Explanation:

Based on user testing results, the Smart Campus Event Hub MVP successfully achieved its main objectives.

The validation results showed:

- **100% task completion rate**
- **Average feedback score: 4.9 / 5**
- **Average interest level: 4.9 / 5**
- Users successfully completed student, organizer, and administrator workflows.

The core features were validated:

- Event discovery.
- Search and filtering.
- Event detail viewing.
- Event registration.
- My Events participation tracking.
- Favorites management.
- Event reviews.
- Admin event management.

However, minor improvements are recommended before the final Lab 14 presentation, including improving search functionality, enhancing analytics, and refining responsive design.

The MVP does not require major changes because the main problem of helping students discover and manage campus events has been successfully validated.
