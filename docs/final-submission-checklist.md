# Slide 2 — Problem and Target Users

## Target Users

- University students
- Student clubs and organizations
- Event organizers
- University administrators

## Problem

Campus events are often promoted through multiple channels such as social media, messaging groups, posters, and university websites.

Students frequently:

- miss important events,
- receive information too late,
- struggle to register,
- cannot easily track the events they joined.

Organizers also find it difficult to manage registrations and monitor participation.

**Speaker Notes**

Explain that the project solves the problem of scattered event information by providing one centralized event management platform.

# Suggested Q&A

### Why not continue using social media?

Because information is scattered, duplicated, and difficult to search. Smart Campus Event Hub organizes events into one searchable platform.

### Why use localStorage?

The project is an educational MVP. localStorage simulates data persistence without requiring a backend.

### How can this become a production system?

By integrating a backend database, secure authentication, cloud hosting, email notifications, and role-based access control.

### How does this benefit the university?

It improves communication, increases student participation, simplifies event management, and provides useful analytics for organizers.

### What is the biggest strength of the project?

A complete end-to-end workflow that allows students to discover, register, manage participation, while enabling administrators to manage events and monitor engagement from one centralized system.
