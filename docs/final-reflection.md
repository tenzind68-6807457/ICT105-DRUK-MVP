# Final Reflection

## 1. What We Built

Our team developed the **Smart Campus Event Hub**, a web-based MVP that helps university students discover campus events, register for activities, and stay informed through a centralized platform. The prototype includes event listing, event details, search and filtering, event registration, a student dashboard, and an organizer/admin dashboard for managing campus events.

---

## 2. What We Learned About Users

Through customer discovery and usability testing, we learned that first-year and international students often miss campus events because information is scattered across multiple communication channels. Users preferred a simple interface with centralized event information, easy navigation, and a straightforward registration process. Feedback also showed that clear search and filtering features significantly improve the user experience.

---

## 3. What We Learned About Requirements

We learned that gathering user feedback is essential for defining accurate system requirements. Functional requirements such as event listing, search and filtering, event registration, and event management directly addressed the problems identified during customer discovery. Maintaining requirement traceability throughout the project helped ensure that the prototype remained aligned with user needs.

---

## 4. What We Improved After Testing

Based on usability testing and validation feedback, we improved the visibility of the search and filter controls, clarified the event registration process, enhanced event status labels, strengthened form validation, and improved the layout of the organizer/admin dashboard. These improvements increased usability and made the prototype more consistent with user expectations.

---

## 5. What Was Difficult Technically

The main technical challenges included maintaining consistent data using browser LocalStorage, implementing responsive layouts across different devices, connecting multiple HTML pages, and ensuring that all documentation, prototype features, screenshots, and requirements remained aligned throughout the project.

---

## 6. What We Would Improve Next

For future development, we would integrate a secure backend database, implement user authentication, add real-time event notifications, improve the event calendar, provide advanced search and filtering options, and support live synchronization of event information across devices.
