# Smart Campus Event Hub Acquisition Metrics

## Purpose

The purpose of this acquisition metrics plan is to measure how effectively the Smart Campus Event Hub landing page attracts students, encourages them to explore campus events, try the prototype, and provide feedback for future improvements.

The metrics focus on the complete user journey:

Landing Page Visitor  
→ CTA Click  
→ Prototype Demo  
→ Event Discovery / Registration  
→ User Feedback  
→ Conversion

---

# Metric Definitions

| Metric ID | Metric | Category | Definition | Formula | Data Source | Success Target |
|-----------|----------|----------|------------|----------|-------------|----------------|
| M-01 | Landing Page Visitors | Awareness | Number of students who open the Smart Campus Event Hub landing page. | Count all landing page visitors. | Manual tracking / browser analytics / spreadsheet | 50 visitors |
| M-02 | CTA Click Rate | Action | Number of users who click the main CTA button to explore the event platform or try the prototype. | CTA Clicks ÷ Landing Page Visitors × 100 | JavaScript click counter / spreadsheet | 40% |
| M-03 | Prototype Demo Views | Engagement | Number of users who successfully access and explore the Smart Campus Event Hub prototype. | Count prototype page visits. | Prototype navigation logs / manual tracking | 30 users |
| M-04 | Event Interaction Attempts | Engagement | Number of users who search events, view event details, register, or save events as favorites. | Count users completing event actions. | Prototype logs / LocalStorage data | 20 users |
| M-05 | Feedback Responses | Feedback | Number of users who submit usability feedback after testing the prototype. | Count submitted feedback forms. | Google Form / feedback spreadsheet | 10 responses |
| M-06 | Conversion Rate | Conversion | Percentage of landing page visitors who become active prototype users. | Prototype Users ÷ Landing Page Visitors × 100 | Spreadsheet | 25% |

---

# Measurement Plan

## M-01 Landing Page Visitors

### Purpose:
Measure awareness and interest in the Smart Campus Event Hub platform.

### Collection Method:
Record visitors who access the landing page through manual logs, browser analytics, or simulated tracking.

### Frequency:
Daily during user testing and validation activities.

---

## M-02 CTA Click Rate

### Purpose:
Measure whether users are interested enough to explore the Smart Campus Event Hub prototype.

### Collection Method:

Track clicks on:

- Try Smart Campus Event Hub Demo
- Explore Campus Events
- Start Event Discovery

### Formula:

CTA Click Rate = CTA Clicks / Landing Page Visitors × 100

---

## M-03 Prototype Demo Views

### Purpose:

Measure how many visitors continue from the landing page and explore the working prototype.

### Collection Method:

Count users who successfully open the Smart Campus Event Hub prototype.

Users are considered engaged when they access features such as:

- Event Listing Page
- Event Details Page
- Search and Filter
- Registration System
- Favorites Page

### Formula:

Demo View Rate = Prototype Views / CTA Clicks × 100

---

## M-04 Event Interaction Attempts

### Purpose:

Measure whether users actively interact with campus event features.

### Collection Method:

Track users who perform actions such as:

- Searching campus events
- Filtering by category
- Viewing event details
- Registering for events
- Saving favorite events

### Formula:

Event Interaction Rate = Active Users / Prototype Users × 100

---

## M-05 Feedback Responses

### Purpose:

Measure user satisfaction and collect improvement suggestions after using the prototype.

### Collection Method:

Collect feedback through:

- Google Forms
- User testing surveys
- Usability testing records

Feedback focuses on:

- Ease of navigation
- Usefulness of event discovery
- Registration experience
- Favorite event feature
- Dashboard usability

### Formula:

Feedback Rate = Feedback Responses / Prototype Users × 100

---

## M-06 Conversion Rate

### Purpose:

Measure how many landing page visitors become active Smart Campus Event Hub users.

### Collection Method:

Compare landing page visitors with users who accessed and interacted with the prototype.

### Formula:

Conversion Rate = Prototype Users / Landing Page Visitors × 100

---

# Data Collection Method

The Smart Campus Event Hub prototype currently uses a frontend-based system without a production backend database.

Therefore, acquisition metrics will be collected using:

- Manual spreadsheet tracking
- JavaScript click tracking (if implemented)
- Prototype navigation logs
- Browser LocalStorage records
- User testing results
- Google Form feedback responses

The prototype uses LocalStorage to simulate:

- User accounts
- Event registrations
- Favorite events
- Event participation history

---

# Success Criteria

| Metric | Target |
|---------|---------|
| Landing Page Visitors | ≥ 50 |
| CTA Click Rate | ≥ 40% |
| Prototype Demo Views | ≥ 30 |
| Event Interaction Attempts | ≥ 20 |
| Feedback Responses | ≥ 10 |
| Conversion Rate | ≥ 25% |

---

# Improvement Plan

If acquisition metrics are below the expected target, the team will:

- Improve the landing page headline to clearly communicate the value of finding campus events easily.
- Make CTA buttons more visible and action-oriented.
- Improve event categories and search filters based on user feedback.
- Simplify the event registration process.
- Improve dashboard and favorite event visibility.
- Promote the platform through student communication channels such as:
  - University student groups
  - Club communities
  - Campus social media pages
  - Orientation activities

---

# Expected Outcome

The acquisition metrics will help Team DRUK evaluate whether Smart Campus Event Hub successfully attracts students, supports event discovery, encourages participation, and provides enough evidence for future improvements.
