# User Testing Plan

## 1. Testing Objective

The objective of this user testing is to evaluate whether the **Smart Campus Event Hub** enables students to easily discover campus events, search and filter activities, view event details, register for events, and navigate the Student Dashboard. The testing also evaluates whether organizers can efficiently create and manage campus events through the Organizer/Admin Dashboard. The results will identify usability issues and improvements before the final submission in Lab 14.

---

## 2. Test User Profile

| User Type | Number of Testers | Why This User Type Matters |
| --- | ---: | --- |
| First-year and international students | 3 | Primary users who need a centralized platform to discover and register for campus events. |
| Student club organizers / Administrators | 2 | Secondary users responsible for creating, updating, and managing campus events. |

---

## 3. Testing Tasks

| Task ID | User Task | Related Requirement | Success Criteria | Observation Focus |
| --- | --- | --- | --- | --- |
| T01 | Open the homepage and explain the purpose of the Smart Campus Event Hub. | FR-01 | User correctly explains the purpose of the platform. | Clarity of homepage and value proposition. |
| T02 | Search for a campus event using the search bar and category filter. | FR-03 | User successfully finds the required event. | Search and filter usability. |
| T03 | Open an event and explain its details and status. | FR-04, FR-08 | User understands the event information and status. | Clarity of event details and status labels. |
| T04 | Register for a campus event using the registration form. | FR-05, FR-09 | User completes the registration without assistance. | Form usability, validation, and confirmation feedback. |
| T05 | View registered events in the Student Dashboard. | FR-06 | User successfully locates their registered events. | Dashboard layout and information visibility. |
| T06 | Create or manage an event through the Organizer/Admin Dashboard. | FR-02, FR-07, FR-10 | Organizer successfully creates or updates an event. | Ease of event management and role-based access. |

---

## 4. Testing Procedure

1. Briefly explain the purpose of the usability test.
2. Ask each participant to complete the testing tasks independently.
3. Avoid providing assistance unless the participant is unable to continue.
4. Record task completion time, observations, comments, and usability issues.
5. Ask participants for overall feedback and suggestions for improvement.

---

## 5. Ethical Reminder

Participants will be informed that the prototype is developed for academic purposes only. No unnecessary personal information will be collected, and all feedback will be used solely to improve the Smart Campus Event Hub prototype before the final project submission. Participation is voluntary, and all responses will be treated confidentially.
