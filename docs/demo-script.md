# Demo Script

## Demo Objective

Demonstrate how the Smart Campus Event Hub helps first-year and international students discover campus events, search and filter activities, view event details, register for events, and enables organizers to manage campus events through a centralized web platform.

## Demo Flow

| Step | Screen / Feature | What Presenter Says | Requirement ID | Expected User Value |
| --- | --- | --- | --- | --- |
| **1** | Homepage | Introduce the problem of scattered campus event information and explain how Smart Campus Event Hub provides one centralized platform for students. | **FR-01** | Students quickly understand the purpose of the platform. |
| **2** | Event Listing | Show the centralized event list and explain how students can browse available campus activities. | **FR-01** | Students can easily discover upcoming campus events. |
| **3** | Search & Filter | Demonstrate searching events by keyword and filtering by category. | **FR-03** | Students find relevant events more efficiently. |
| **4** | Event Details | Open an event to display its description, date, time, venue, organizer, and event status. | **FR-04, FR-08** | Students receive complete event information before registering. |
| **5** | Event Registration | Demonstrate the registration form and show successful registration with validation. | **FR-05, FR-09** | Students can register quickly and accurately. |
| **6** | Student Dashboard | Display registered events and participation status. | **FR-06, FR-08** | Students can track their event registrations. |
| **7** | Organizer/Admin Dashboard | Demonstrate creating, editing, deleting events, managing participant registrations, and role-based access. | **FR-02, FR-07, FR-10** | Organizers can efficiently manage campus events. |
| **8** | Closing & Startup Metrics | Present dashboard statistics, summarize project benefits, and explain future improvements. | **NFR-04** | Demonstrates project readiness and value for the university community. |

---

## Closing Statement

The **Smart Campus Event Hub** addresses the problem of scattered campus event information by providing a centralized platform where students can easily discover, search, and register for university activities. At the same time, organizers can efficiently publish and manage events through a simple web-based interface. Our MVP demonstrates that a centralized event management system can improve student participation, reduce missed opportunities, and create a more connected campus community.
