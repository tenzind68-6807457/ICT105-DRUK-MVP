# Smart Campus Event Hub Demo Outline for the Final Pitch

## 1. Opening Problem — 30 seconds

University students often miss important campus events because information is scattered across multiple platforms such as social media pages, LINE groups, university emails, posters, and different announcement channels.

First-year and international students especially face difficulties discovering workshops, competitions, seminars, and student activities because they do not know where to find complete and reliable event information.

**Opening question:**

"How many different platforms should a student check just to find one campus event that matches their interests?"

The Smart Campus Event Hub solves this problem by providing one centralized platform for discovering, registering, and managing campus activities.

---

# 2. Target User — 20 seconds

The main target users are:

### Students
- First-year students who need easier access to campus activities.
- International and exchange students who are unfamiliar with university event channels.
- Students who want to discover, register, save, and track events.

### Secondary Users

- Student clubs and organizers who need a platform to publish and manage events.
- Campus administrators who monitor event information and participation.

---

# 3. Product Solution — 30 seconds

Smart Campus Event Hub provides:

- Centralized campus event discovery.
- Search and category filtering.
- Detailed event information.
- Online event registration.
- My Events page for tracking registered activities.
- Favorites feature for saving interesting events.
- Post-event reviews and feedback.
- Admin dashboard for event management and analytics.

The current version is a frontend-only classroom MVP developed using:

- HTML5
- CSS3
- JavaScript ES6
- Browser LocalStorage for simulated data storage

The prototype demonstrates the main user experience without a production backend, real authentication, or live database.

# 5. Evidence — 45 seconds

## Customer Discovery Evidence

The team conducted customer discovery with 20 Rangsit University students.

Key findings:

- Students receive event information from many different channels.
- Important announcements are often missed.
- Students depend on friends or social media to discover activities.
- Students need a centralized event platform.

The Smart Campus Event Hub was created to solve this information fragmentation problem.

---

## Validation and Testing Evidence

The MVP was validated through usability testing.

Results:

- Total test users: 10
- Task completion rate: 100%
- Average feedback score: 4.9/5
- Average interest level: 4.9/5

Users successfully completed:

- Finding events.
- Viewing event details.
- Registering for activities.
- Managing My Events.
- Saving Favorites.
- Submitting reviews.

User suggestions included:

- More advanced search options.
- Event reminders.
- More dashboard analytics.
- Additional customization features.

# 6. Requirement and Risk Message — 30 seconds

The Smart Campus Event Hub prototype demonstrates the core solution for improving campus event discovery and participation.

The current MVP limitations include:

- No production backend.
- No real authentication system.
- LocalStorage-based simulated data.
- No real-time notifications.
- No live university database connection.

These limitations are intentionally documented because the project focuses on validating the MVP concept and user experience.

Future development would include:

- Secure authentication.
- Backend database.
- Real-time notifications.
- Advanced recommendation system.
- Integration with university systems.

---

# 7. Closing Value Message — 20 seconds

"Smart Campus Event Hub helps students discover opportunities they might otherwise miss. By bringing campus events, registration, participation tracking, favorites, and feedback into one centralized platform, it improves communication between students, organizers, and the university community."

**Call to action:**

"Explore an event, register for an activity, and experience a simpler way to stay connected with campus life."
