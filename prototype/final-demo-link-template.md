## Notes

### Purpose

The Smart Campus Event Hub is an educational Minimum Viable Product (MVP) developed for the ICT105 Fundamental Technology Entrepreneurship course at Rangsit University. The prototype demonstrates how students can discover, register for, and manage campus events through a centralized web platform.

---

### Recommended Testing Flow

For the best demonstration experience, please follow these steps:

1. Open the **Landing Page** using the link above.
2. Read the project overview, target users, problem statement, solution, and key features.
3. Click the **Try Demo** button to open the working prototype.
4. Explore the prototype by completing the following tasks:
   - Browse available campus events.
   - Search and filter events by keyword or category.
   - View detailed event information.
   - Register for an available event.
   - View registered events through the **My Events Dashboard**.
   - Submit an event review after viewing a completed event.
   - Explore the About and Contact pages.
5. (Optional) Access the Admin Dashboard to review the administrator event management functions.

---

### Login Information

The prototype uses simulated authentication for demonstration purposes.

- Use the sample accounts provided within the prototype if required.
- User authentication is simulated using browser **localStorage**.
- No real student accounts or university systems are connected.

---

### Demonstration Data

The prototype uses sample data for demonstration purposes, including:

- Sample student accounts
- Sample campus events
- Sample event registrations
- Sample event reviews
- Administrator-managed event records

All data is stored locally in the browser using **localStorage**.

---

### Prototype Limitations

This project is a classroom MVP and has several intentional limitations:

- It is a frontend-only web prototype.
- No live database is connected.
- No university authentication system is used.
- No real email notifications are sent.
- No payment or external services are integrated.
- Event information is simulated using sample data.
- Data will remain available only within the current browser unless browser storage is cleared.

These limitations are appropriate for demonstrating the core functionality of the Smart Campus Event Hub while validating the project's problem-solution fit.

---

### Browser Recommendation

For the best experience, use one of the following browsers:

### Privacy Notice

The prototype collects only the minimum information required for demonstration purposes. All information is stored locally in the browser using **localStorage**. No personal information is transmitted to external servers, and only sample or demonstration data should be used while testing the system.
