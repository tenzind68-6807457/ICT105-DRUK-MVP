## Prototype Description

The Smart Campus Event Hub is an interactive web-based MVP developed using HTML5, CSS3, JavaScript (ES6), and browser localStorage. The prototype demonstrates the complete user workflow for discovering, registering for, and managing campus events.

### Main Features

- Homepage
- User Login
- User Registration (Sign Up)
- Browse Campus Events
- Search and Filter Events
- Event Details
- Event Registration
- My Events Dashboard
- Event Review and Feedback
- Admin Dashboard
- About Page
- Contact Page
- Responsive User Interface
- Browser localStorage Data Simulation

## Demo Instructions

1. Open the Landing Page.
2. Click **Try Demo**.
3. Sign up for a new account or log in using the demo account.
4. Browse available campus events.
5. Search or filter events by keyword or category.
6. Open an event to view its details.
7. Register for an event.
8. View registered events in **My Events Dashboard**.
9. Submit an event review after a completed event.
10. Explore the Admin Dashboard to manage campus events.

---

## Notes

- This is a classroom MVP prototype developed for ICT105 Fundamental Technology Entrepreneurship.
- The prototype uses browser localStorage to simulate persistent data storage.
- All accounts, event records, registrations, and reviews are stored locally within the browser.
- The prototype is frontend only and does not connect to a live server or production database.
- User authentication is simulated for demonstration purposes.
- Sample event data is included to demonstrate system functionality.
